- 포코타이쿤 전용 클라이언트 파일만 SHA-256과 크기를 확인한 뒤 게시합니다.
- 서버 전용 구현, 운영 설정, 데이터베이스 정보, 비밀키와 관리 기능은 배포하지 않습니다.
